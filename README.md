# Lou

**Lou** is a short 2D narrative game about loss, memory, and finding your way back to solid ground.

Developed with **Unity and C#**, the game follows Lou through an ordinary walk that gradually turns into something much more personal.

## 🎮 About

Lou is a narrative-focused experience centered around exploration, dialogue, and atmosphere.

The game explores themes of:

- Loss
- Memory
- Anxiety
- Acceptance
- Moving forward

The goal is to tell a small, personal story through gameplay rather than exposition alone.

## ✨ Features

- 2D exploration
- Narrative-driven gameplay
- Dialogue system with typewriter effects
- Dynamic dialogue balloons
- Text effects and character animations
- Unity Input System
- 2D physics and movement
- Hand-drawn artwork

## 🛠️ Built With

- **Unity**
- **C#**
- **TextMeshPro**
- **Unity Input System**
- **Krita**
